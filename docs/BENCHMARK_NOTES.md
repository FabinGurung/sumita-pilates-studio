# Benchmark Notes

The prototype uses Coco Collective and its Punchpass screens as a functional benchmark, not as a brand or content template.

Useful customer-journey patterns observed:

- Schedule, passes, instructors and website links in a simple mobile menu
- Class rows that show time, duration, location, instructor and remaining capacity
- Full-class and waitlist states
- Account sign-in and account creation
- Reservation reminder information with cancellation guidance
- Monthly memberships, drop-ins and class packs
- Advance booking, first-visit arrival and cancellation policies

Original identity used in this project:

- Different business name and logo
- Different colour system and typography
- Original illustrations
- Original page layout and written copy
- Nepal/Pokhara placeholders
